💰 Alke Wallet - Solución FinTech

Alke Wallet es una aplicación web que emula la experiencia de una billetera digital moderna. Este proyecto fue diseñado para gestionar operaciones financieras básicas en un entorno seguro y controlado, priorizando la fluidez de la experiencia del usuario y la integridad de los datos en sesión.

🚀 Características Principales

Gestión de Sesión Dinámica: Sistema de autenticación que valida el formato de credenciales y asegura la persistencia temporal mediante sessionStorage.

Panel de Control (Dashboard): 

Visualización inmediata del saldo disponible y navegación intuitiva hacia operaciones críticas.

Módulo Transaccional: Funcionalidades completas para depositar fondos y realizar transferencias entre cuentas.

Historial de Movimientos: Registro detallado de transacciones para el seguimiento financiero del usuario.

🛠️ Stack Tecnológico

Frontend: HTML5 semántico y CSS3 (diseño responsivo con Bootstrap + Flexbox).Lógica de Negocio: JavaScript potenciado con jQuery para la manipulación eficiente del DOM.Control de Versiones: Git y GitHub para la trazabilidad del código.

Despliegue: GitHub Pages para una disponibilidad inmediata del producto.

⚙️ Instrucciones de Uso

Para garantizar la seguridad y el correcto funcionamiento del simulador, se aplican las siguientes reglas de negocio:

Formato de Usuario: Debe utilizarse una estructura de correo válida (ejemplo@email.com).

Seguridad de Clave: La contraseña debe tener una longitud superior a 6 caracteres.

Entorno de Datos: Los datos se almacenan de forma volátil; al cerrar la pestaña o el navegador, la sesión se reinicia por motivos de seguridad.

💡 Desafío y Aprendizaje

El mayor reto técnico en este proyecto fue la implementación de la arquitectura de datos en el cliente.
Al no utilizar una base de datos persistente, el desafío consistió en estructurar la lógica para que los depósitos y transferencias se reflejaran en tiempo real en el saldo del Dashboard, garantizando que el usuario nunca vea información desactualizada.
